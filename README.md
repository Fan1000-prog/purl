# Purl

Speak softly. Send it clean.

Purl is a free, open-source dictation app for macOS and Windows. Press a hotkey,
talk, press again: your words are transcribed on your machine, cleaned up, and
pasted at the cursor.

> Work in progress. Install steps, a guide and benchmarks will land here before v1.

## Build from source

```bash
cd app && npm ci && npm run tauri build
```
